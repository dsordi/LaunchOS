# LaunchOS

Sistema de inteligência e execução de lançamentos digitais (Nelogica). Second brain / copiloto do Davi Sordi.

## Estrutura
- `CLAUDE.md` — manual de operação (lido no início de cada sessão).
- `LAUNCHOS_PRODUCT_BLUEPRINT.md` — definição do produto.
- `AUDITORIA_LOGICA_DECISAO.md` — auditoria crítica da lógica financeira.
- `biblioteca/` — base de conhecimento consolidada (fontes, fichas, matriz, indicadores, glossário, decisões, método).
- `app/index.html` — MVP do Decisor de Viabilidade + Playbook (abre direto no navegador).

## Como usar o app
Abra `app/index.html` no navegador. Dados salvos localmente no navegador (localStorage) — versão com banco de dados é próximo passo.

> Todo número é premissa `[D]`, não previsão. Faturamento ≠ caixa ≠ lucro.
